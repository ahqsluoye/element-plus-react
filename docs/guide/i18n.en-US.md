# Internationalization and Localization

Element Plus React components use English **by default**. If you want to use other languages, read on to find out how.

## Global Configuration

Element Plus React provides global configuration for internationalization.

## ConfigProvider

Element Plus React provides a component [ConfigProvider](/components/config-provider) to configure internationalization.

```ts [App.tsx]
import { ElConfigProvider } from '@qsxy/element-plus-react';

return (
    <ElConfigProvider locale="zh-cn">
        <App />
    </ElConfigProvider>
);
```
