# DatePicker

Use DatePicker for date selection or input.

## Enter Date

Basic date picker measured by 'day'.

The basic unit is specified by the `type` attribute. Configure shortcut options via `shortcuts`, and set disabled dates via the `disabledDate` function.

<code src="./enter-date.tsx"></code>

## Other Measurements

By extending the basic date picker, you can select week, month, year, or multiple dates.

<code src="./other-measurements.tsx"></code>

## ISO Standard Week Numbers

The International Organization for Standardization (ISO) 8601 defines the calculation of week numbers: each week starts on Monday and ends on Sunday; the first week of each year must contain at least 4 days of that year. Set `isoWeek` to `true` to enable ISO standard week numbers. By default, the date picker displays non-ISO standard week numbers.

<code src="./iso-week.tsx"></code>
